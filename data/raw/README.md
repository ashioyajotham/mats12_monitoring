# Raw question data

`pilot_questions.jsonl` is a deterministic 20-question adaptation of the **AI2 Reasoning
Challenge (ARC), Challenge configuration, validation split**. The source revision, input hash,
selection procedure, and output hash are recorded in `pilot_questions.manifest.json`.

ARC was introduced by Peter Clark, Isaac Cowhey, Oren Etzioni, Tushar Khot, Ashish Sabharwal,
Carissa Schoenick, and Oyvind Tafjord in *Think you have Solved Question Answering? Try ARC, the AI2
Reasoning Challenge* (2018). The pinned source is distributed by AllenAI at
<https://huggingface.co/datasets/allenai/ai2_arc> under the
[Creative Commons Attribution-ShareAlike 4.0 International license](https://creativecommons.org/licenses/by-sa/4.0/).

The selected question text and normalized records retain that CC BY-SA 4.0 license; the
repository's MIT license applies to code and does not replace the dataset license. Redistribution
or adaptation of these records must preserve attribution and share-alike terms.
